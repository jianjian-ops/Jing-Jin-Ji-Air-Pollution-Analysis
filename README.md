# 京津冀空气污染协同防控数据分析项目

## 项目概述
本项目以京津冀区域为空间研究对象，基于多源环境大数据，对区域空气污染的时空演化特征及跨区域传输机制进行系统分析，并构建高精度污染预测模型，为区域协同空气污染防控提供数据支持与决策依据。

## 数据来源
- 中国环境监测总站发布的空气质量数据（AQI、PM2.5、NO2、O3_8H、CO 等）
- NOAA 提供的气象数据（气温、风速、降水量、海平面气压等）
- 时间范围：2020–2024 年
- 覆盖城市：北京、天津、石家庄、保定、唐山、张家口等

## 数据处理与分析
- 对多源数据进行清洗与整合，处理缺失值与异常值（KNN 插值、线性插值、Winsorize）
- 构建时序特征与滞后特征，刻画污染物时序变化规律
- 进行特征工程与多重共线性控制（相关性分析、VIF、PCA）
- 分析空气污染的时空分布特征及城市间影响关系

## 建模方法
- 构建融合物理约束的时空因果图模型，刻画区域污染传输路径
- 采用 Transformer 提取时序特征，增强时间依赖建模能力
- 使用 LSTM 对预测残差进行修正，提高预测稳定性
- 基于 XGBoost 构建高精度空气质量预测模型

## 关键结果
- 时空因果模型在测试集上的 R² 达到 0.86
- XGBoost 预测模型在各城市 AQI 预测中 R² 均高于 0.99
- 识别出京津冀区域内主要污染传输路径
- 支持 3–6 小时短期预测及 72 小时滚动预测分析

## 使用工具
- R（数据处理、建模与可视化）
- XGBoost
- 时序分析与时空数据建模方法
- 数据可视化（ggplot2、plotly）

## 项目价值
本项目展示了多源环境数据在空气污染治理中的分析与应用能力，体现了数据分析与建模在公共治理和区域协同决策中的实际价值。
